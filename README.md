# msgql
ЗадаЧат — корпоративная система управления задачами и коммуникациями.
ЗадаЧат — это индивидуальная русскоязычная платформа для управления проектами, задачами и командной коммуникации. Разработана с нуля на чистом PHP & MariaDB с использованием практик безопасности и реального времени (Server-Sent Events), с ориентацией на недорогие shared-хостинги.

Детальный функционал: https://pmaker.ru/задачат_функционал/

Это self-hosting решение для небольших команд, которые ценят безопасность, контроль над данными и функциональность без ежемесячных платежей. Система не пытается конкурировать с Asana по количеству функций, интеграций или мобильным приложениям, но пытается приблизиться к ней, улучшаясь во встроенных возможностях просмотра файлов, гибкости прав доступа, стоимости владения и независимости от облачных провайдеров.

1. Выбрать shared-хостинг с PHP8+, MariaDB 10+
2. Создать новую базу данных в PhpMyAdmin хостинга или в Adminer, открыв файл lib/a.php
3. Отредактировать в дампе базы данных !one_time/msgql_clear_db.sql имя базы  (USE)
4. Импортировать базу из дампа и настроить её в lib/config.php
5. Создать первого пользователя-администратора в таблице users
6. Зарегистрировать проект в Firebase https://console.firebase.google.com/ и создать VAPID-ключи для пуш-уведомлений
7. Опционально: импорт данных из Asana api/asana_import_ui.php: предварительно создать пользователей системы (admin.php), которых можно будет сопоставить с пользователями Asana и импортировать их данные в базу
